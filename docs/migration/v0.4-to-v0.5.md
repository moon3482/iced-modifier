# Migration: v0.4 → v0.5

## New: `TextAlign` / `TextAlignY` enums

`TextAlign` and `TextAlignY` are now available in the prelude for explicit text alignment control.

```rust
use iced_modifier::prelude::*;

Text::new("Hello")
    .text_align(TextAlign::Center)      // horizontal
    .text_align_y(TextAlignY::Bottom)   // vertical
```

**`TextAlign` variants**: `Start`, `Center`, `End`, `Justify`, `Left`, `Right`
**`TextAlignY` variants**: `Top`, `Center`, `Bottom`

> Prefer `Start`/`End` over `Left`/`Right` for RTL language support.

Existing `.text_center()` and `.text_align_x()` methods continue to work unchanged.

## Changed: Button direct style

Button style properties (`background_color`, `corner_radius`, `border`, `shadow`, `text_color`) are now applied directly to the iced Button via its `.style()` API, instead of through Container wrapping.

```rust
// v0.4: styles applied via Container wrapper (visual differences possible)
// v0.5: styles applied directly to iced Button
Button::new(text("Submit"))
    .on_press(Message::Submit)
    .background_color("#1976D2")
    .corner_radius(8)
    .text_color("#FFF")
```

**What changed**: The rendering behavior may differ slightly because colors, borders, and shadows now render on the button element itself. The API (method signatures) is unchanged.

**Action required**: If you relied on the Container-wrapping behavior for Button styling, visually verify your buttons after upgrading.
